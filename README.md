# SpendWise

A personal expense and savings manager built with ASP.NET Core MVC, Entity Framework Core and MySQL.

## Features
- Monthly income and savings plan (fixed amount or percentage)
- Daily spending allowance calculation
- Add, edit, delete and filter expenses
- Record actual savings and track progress
- Dashboard with category breakdown and budget warnings

## Setup
1. Install MySQL and create a database named spendwise.
2. Check the connection string in appsettings.json.
3. Run: dotnet ef database update
4. Run: dotnet run
5. Open http://localhost:5210
